# 망우청소년센터 네컷 포토부스

망우청소년센터 행사에서 사용할 수 있는 네컷사진 포토부스 웹앱입니다.

## 기능

- 시작 버튼
- 카운트다운
- 촬영 버튼 클릭 시 5초 간격으로 8장 연속 촬영
- 8장 중 4장 사진 선택 / 삭제
- 원본, 화사하게, 뽀샤시, 선명하게, 필름톤 사진 보정
- 다음 화면에서 블랙, 화이트, 하트, 카메라 필름지, 뽀짝, 망고미 네컷 프레임 선택
- 망고미 프레임은 캐릭터 PNG를 활용해 캔버스에서 직접 생성하고, 하단에는 망우청소년센터 로고 표시
- 선택한 네컷 프레임에 사진 합성 미리보기
- 최종 이미지 저장
- 저장 시 네컷 프레임을 2장 나란히 붙인 2:2.96 비율 PNG로 다운로드

## GitHub Pages 배포

이 폴더의 `index.html`, `styles.css`, `app.js`를 GitHub 저장소에 올린 뒤 GitHub Pages를 켜면 바로 사용할 수 있습니다.

카메라 기능은 브라우저 보안 정책상 `https` 주소에서 가장 안정적으로 동작합니다. GitHub Pages 주소는 기본적으로 `https`라서 행사 현장에서 사용하기 좋습니다.
